# Simulador de Planejamento Tributário — Reforma Tributária

Compara Simples Nacional × Lucro Presumido × Lucro Real × Simples com IBS/CBS regular na transição 2026–2033,
com base nas regras da Calculadora RTC da Receita Federal (código aberto, MIT).

- `index.html`: aplicação completa em um único arquivo (versão que guarda os dados no navegador).
- Publicação: a Vercel publica automaticamente a cada envio na branch `main`.

Portal: https://simulador-fiscalbr-001.vercel.app/
